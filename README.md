# Introduction to End-to-End Robotics — Slidev Project

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Edit the slides

Open `slides.md`. Each slide is separated by `---`.

## Build for publishing

```bash
npm run build
```

The built site will be in `dist/`.

## Export to PDF

```bash
npm run export
```

If export asks for browser dependencies, run:

```bash
npx playwright install chromium
```
